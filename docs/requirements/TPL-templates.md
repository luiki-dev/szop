# Templates (TPL)

Templates: reusable sets of items that new lists start from. Part of the [functional requirements](functional-requirements.md), which explain how requirements and their criteria are written and show the status of every requirement.

## TPL-1

🎯 [MVP] · ❔ Draft (0 of 4) · ❔ Criteria not finalized

Create a template from scratch, or from a list ([LST-6](LST-shopping-lists.md#lst-6)).

| ID | Criterion | Status |
|---|---|---|
| TPL-1.1 | A user creates a template from scratch, giving it a name. | ❔ Draft |
| TPL-1.2 | "Save as template" on a list creates a template from its items ([LST-6](LST-shopping-lists.md#lst-6)). | ❔ Draft |
| TPL-1.3 | "Templates" in the menu lists the user's templates. | ❔ Draft |
| TPL-1.4 | A template belongs to its owner and is never shared. | ❔ Draft |

## TPL-2

🎯 [MVP] · ❔ Draft (0 of 1) · ❔ Criteria not finalized

Edit a template's name and items, the same way as a list but without checking items off.

| ID | Criterion | Status |
|---|---|---|
| TPL-2.1 | A user renames a template, and adds, edits and removes its items as on a list, without checking them off. | ❔ Draft |

## TPL-3

🎯 [MVP] · ❔ Draft (0 of 3) · ❔ Criteria not finalized

Create a new list from a template. Delete a template.

| ID | Criterion | Status |
|---|---|---|
| TPL-3.1 | A user creates a new list from a template: the list gets the template's items, all unchecked, and the template does not change. | ❔ Draft |
| TPL-3.2 | Later changes to the list or to the template do not affect the other. | ❔ Draft |
| TPL-3.3 | A user deletes a template; lists created from it stay as they are. | ❔ Draft |
