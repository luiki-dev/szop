# Templates (TPL)

Templates: reusable sets of items that new lists start from. Part of the [functional requirements](functional-requirements.md), which explain how requirements and their criteria are written and show the status of every requirement.

## TPL-1

🎯 [MVP] Create a template from scratch, or from a list ([LST-6](LST-shopping-lists.md#lst-6)).

## TPL-2

🎯 [MVP] Edit a template's name and items, the same way as a list but without checking items off.

## TPL-3

🎯 [MVP] Create a new list from a template. Delete a template.
