# Language (LNG)

The language of the app's texts. Part of the [functional requirements](functional-requirements.md), which explain how requirements and their criteria are written and show the status of every requirement.

## LNG-1

🔜 [Later] · ❔ Draft (0 of 5) · ❔ Criteria not finalized

The user chooses the language: English or Polish. Without a choice, the app uses the browser's language.

| ID | Criterion | Status |
|---|---|---|
| LNG-1.1 | The user can switch the language between English and Polish at any time. | ❔ Draft |
| LNG-1.2 | Without a choice, the app uses the first of the browser's preferred languages that it offers, and English when it offers none of them. | ❔ Draft |
| LNG-1.3 | A chosen language survives a reload. | ❔ Draft |
| LNG-1.4 | Every text of the UI, page titles and messages included, appears in the chosen language. | ❔ Draft |
| LNG-1.5 | The page declares its current language, so screen readers read it in that language. | ❔ Draft |
