# Catalog (PRD)

The catalog of products: maintaining it, browsing it and searching it. Part of the [functional requirements](functional-requirements.md), which explain how requirements and their criteria are written and show the status of every requirement.

## PRD-1

🎯 [MVP] Create, edit and delete catalog products (name, default category, default unit, default price).

## PRD-2

🎯 [MVP] Browse the catalog by category, and search it by name.

## PRD-3

🎯 [MVP] Deleting a product does not affect list items created from it.
