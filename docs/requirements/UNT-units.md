# Units (UNT)

The units of measure items and products use. Part of the [functional requirements](functional-requirements.md), which explain how requirements and their criteria are written and show the status of every requirement.

## UNT-1

🎯 [MVP] · 🚧 In progress (0 of 4) · ❔ Criteria not finalized

Add, rename and delete units. Items that already use a unit keep its label.

| ID | Criterion | Status |
|---|---|---|
| UNT-1.1 | A new workspace starts with the default units, such as pcs, kg, g, l, ml and pack. | 🚧 [PH-16b](../roadmap.md#ph-16b-workspace-from-the-default-data) |
| UNT-1.2 | A user adds, renames and deletes units. | ❔ Draft |
| UNT-1.3 | Items that use a unit keep its label when the unit is renamed or deleted. | ❔ Draft · [OP-041](https://github.com/luiki-dev/szop/issues/100) |
| UNT-1.4 | Deleting a unit removes it as the default unit of the products that had it. | ❔ Draft · [OP-041](https://github.com/luiki-dev/szop/issues/100) |
