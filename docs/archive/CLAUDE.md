# docs/archive

Frozen records. Nothing in this folder is a source of current state.

- **Never read these files to learn what is open, planned or decided now.** Open points are GitHub issues labelled `open-point` (`gh issue list --repo luiki-dev/szop --label open-point --state all --limit 200`, or the [Open Points view](https://github.com/users/luiki-dev/projects/3/views/5), which shows open ones only); phases and their plans are in `docs/roadmap.md`; decisions are in `docs/decisions/`.
- **Never edit them,** except to fix a link that broke. Specs, plans and audits link here on purpose, to show the state of their day.
- `open-points.md`: the open points register, archived by [ADR 0027](../decisions/0027-open-points-on-github.md).
